# 🚀 Landing Page com GitHub Pages

Projeto didático desenvolvido para demonstrar a criação e publicação de uma Landing Page utilizando **HTML5, CSS3, JavaScript e GitHub Pages**.

---

## 📚 Objetivo

O objetivo deste projeto é ensinar os conceitos básicos de desenvolvimento web e demonstrar como publicar gratuitamente um site utilizando o **GitHub Pages**.

Durante o projeto serão utilizados:

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

---

## 🖥️ Tecnologias

### HTML5

Utilizado para criar a estrutura e o conteúdo da página.

### CSS3

Utilizado para estilizar a página, trabalhando conceitos como:

- cores;
- espaçamentos;
- fontes;
- Flexbox;
- responsividade;
- efeitos de hover.

### JavaScript

Utilizado para adicionar interatividade à página.

Neste projeto utilizamos JavaScript para:

- capturar um botão;
- trabalhar com eventos;
- alterar elementos HTML;
- apresentar uma mensagem ao usuário;
- atualizar automaticamente o ano do rodapé.

```text
index.html
```

no seu navegador.

---

# 🌎 Publicando no GitHub Pages

## 1. Criar uma conta no GitHub

Acesse o GitHub e crie sua conta caso ainda não possua.

---

## 2. Criar um repositório

Clique em:

```text
New repository
```

Nome do repositório:

```text
landing-page-github-pages
```

Descrição:

```text
Projeto didático de uma Landing Page desenvolvida com HTML5, CSS3 e JavaScript para aprender publicação de sites utilizando GitHub Pages.
```

Defina o repositório como:

```text
Public
```

Depois clique em:

```text
Create repository
```

---

## 3. Enviar os arquivos

Envie para o repositório:

```text
index.html
README.md

css/
   style.css

js/
   script.js
```

É muito importante que o arquivo principal tenha exatamente o nome:

```text
index.html
```

O GitHub Pages procura esse arquivo para carregar a página inicial do site.

---

# ⚙️ Ativando o GitHub Pages

Dentro do repositório, acesse:

```text
Settings
```

Depois:

```text
Pages
```

Em **Build and deployment**, escolha:

```text
Source:

Deploy from a branch
```

Em **Branch**, escolha:

```text
main
```

e:

```text
/root
```

Clique em:

```text
Save
```

# 🎓 Atividade para os alunos

Depois de publicar o projeto, faça pelo menos três modificações.

1. Altere as cores da Landing Page.
2. Altere os textos.
3. Adicione uma nova seção.
4. Adicione uma imagem.
5. Modifique o comportamento do botão JavaScript.

Depois faça um novo commit e verifique se as alterações apareceram no site publicado.
