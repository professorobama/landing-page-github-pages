Sobre o Projeto

Este projeto foi desenvolvido para praticar os conceitos básicos de HTML5, CSS3 e JavaScript.

Além disso, aprenderemos como publicar gratuitamente uma página na internet utilizando o GitHub Pages.

Tecnologias utilizadas

HTML5

Responsável pela estrutura e pelo conteúdo da nossa página.

CSS3

Responsável pelas cores, tamanhos, posicionamento e aparência da página.

JavaScript

Responsável pela interatividade e comportamento da página.
